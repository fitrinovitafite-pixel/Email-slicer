# Email Slicer

A beginner-friendly Python project that separates an email address into a username and domain.

## Features

- Takes an email address as user input
- Extracts the username
- Extracts the domain
- Simple command-line interface

## Technologies

- Python

## How to Use

1. Run the Python program.
2. Enter an email address when prompted.
3. The program will display the username and domain.

## Example

Input:
```text
fitri@gmail.com

output:
Username: fitri
Domain: gmail.com
